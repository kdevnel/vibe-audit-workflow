# Vibe Code Audit Framework
A comprehensive code audit framework for reviewing apps built by non-developers.

## 🎯 **What This Workflow Guide Gives You:**

### **📋 Step-by-Step Instructions**
- Clear numbered steps from setup to final report
- Specific commands to run at each stage
- Exact timeframes for each phase (30 min → 2-4 hours → 1-2 hours → 1 hour)

### **🔗 Smart References to Prompt Library**
- Instead of duplicating prompts, it tells you exactly which prompt to use when
- Clear indicators like: `📖 Reference: See "Initial Security Scan Prompt" in AUDIT_PROMPT_LIBRARY.md`
- Context for when to use each specialized prompt

### **⚡ Multiple Audit Speeds**
- **Full Audit** (4-7 hours): Complete security and quality review
- **Speed Audit** (15 minutes): Critical issues only when time is limited
- **Phase-by-phase breakdown** so you can stop and resume

### **🛠️ Ready-to-Use Commands**
- All the grep patterns and file discovery commands you need
- Copy-paste bash commands for automated scanning
- File location helpers for different tech stacks

### **📊 Clear Output Structure**
- Exact template for your audit report
- Risk assessment matrix
- Implementation timeline with priorities

## 🚀 **How to Use This:**

1. **Open COMPLETE_AUDIT_WORKFLOW.md** - this is your primary guide
2. **Keep AUDIT_PROMPT_LIBRARY.md open** in another tab for the actual prompts
3. **Follow the numbered steps** in the workflow guide
4. **Reference the prompt library** when the workflow tells you to
5. **Document findings** using the provided templates

This gives you a **professional, repeatable audit process** that you can use on any non-developer built application. The workflow is technology-agnostic but provides specific guidance for common stacks like React/Node.js.
